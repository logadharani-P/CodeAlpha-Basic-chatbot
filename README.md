

# Basic chatbot

## Description

This is a simple chatbot built using python. It responds to user qustions based on predefined answers.

## Features

- Greets the user
- Answers basic questions
- Provides Information 
- Ends the conversation when the user types'bye'

## Technologies

- Python
- VS code

## How to Run

1. Open the project folder.
2. Open terminal.
3. Run:

python chatbot.py
